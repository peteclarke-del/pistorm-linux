The AmigaOS suggestion now takes into account the Kickstart chip fitted in your machine.

## What's new

- **Without a PiStorm, the suggestion is based on the Kickstart you chose on the Machine step,** because that's the chip in your machine.
  - It only suggests releases that run on that chip, preferring one made for it.
  - An A600 or A1200 with an accelerator and a 3.1 chip now gets AmigaOS 3.9. With a 3.2 chip it gets 3.2.
  - 3.2 on a 3.1 chip, which has to load 3.2's own Kickstart parts at every boot, is still offered after those, with the reason.
- **On a PiStorm, nothing changes.** The Kickstart is a file on the SD card, so the best release's own ROM can always be used.
- **If you haven't chosen a Kickstart on a machine without a PiStorm,** the suggestion asks for it.
- **New document:** `docs/os-suggestions.md` lists what is suggested for every machine, accelerator and Kickstart.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
