Fixes for cards booting Emu68 1.1 with an RTG screen, for the games menu, and for NetSurf.

## Fixed

- **A card that boots Emu68 1.1 could crash as Picasso96 started.** The error was #80000004, followed by a Guru Meditation. Emu68 1.1 needs the VideoCore.card 1.5 published with its own release. Cards were given 1.3 from the Emu68-tools package, which only works with Emu68 1.0.
- **The RTG driver now always matches the Emu68 version chosen on the Emu68 step.** 1.1 cards get 1.5, and 1.0 cards keep 1.3.
- **If the 1.1 driver can't be downloaded, the card gets no RTG driver,** rather than one that crashes the machine.

- **The AGS2 games menu now starts when Games software is kept on its own drive.** The menu program went to the drive you chose for Games, but its icon and pictures stayed on System, so double-clicking it did nothing. Software that shares a drawer with what it needs now stays together on the drive you chose for it.
- **NetSurf starts with the lwIP network stack.** It stopped because it couldn't find the usergroup.library that comes with it. That library is now installed where AmigaOS looks for libraries.

If you built a card for Emu68 1.1 with Picasso96 using 0.19.2 or earlier, it has the wrong driver. Either rebuild its System drive, or write its SD card again with Emu68 1.0.7.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
