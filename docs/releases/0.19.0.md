The software warnings now cover software that clashes with other software you've chosen.

## What's new

- **Ticking a package that clashes with one already ticked asks first, and says why.** You get the same **Leave it off** or **Install anyway** choice as for software that doesn't suit your card or AmigaOS.
- **Each clash comes from the software's own documentation.** For example:
  - FBlit with Picasso96: "never install FBlit together with a P96 driver".
  - MCP with VisualPrefs, Birdie, NewIcons, MagicMenu or Scalos.
  - MagicMenu with FreeWheel.
  - NewIcons with DefIcons.
  - lwip-amiga with Roadshow.
- **The suggested set never contains a clash.** Where two recommended packages clash, the first stays and you can add the other yourself, with the warning. Today that means MagicMenu is suggested and FreeWheel isn't.
- **Clashes on your setup are listed on the Review page,** along with anything else that isn't advised, with the reasons.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
