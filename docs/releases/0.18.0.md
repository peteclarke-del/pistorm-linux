Software that is a poor choice for your card now always says why, and the decision is yours.

## What's new

- **Nothing on the Software page is greyed out any more.** If a package doesn't suit your card, or isn't advised on the AmigaOS you're installing, its row says why first.
- **Ticking one asks first.** A dialog gives the reason, with **Leave it off** or **Install anyway**.
- **Several at once, such as after choosing the AmigaOS 3.2 CD:**
  - You're asked when you next open the Software page.
  - It's one dialog with a switch for each package, all off until you turn them on.
- **"Install anyway" is respected.**
  - The build installs the package even if it doesn't suit the hardware.
  - It's saved with your setup.
  - The Review page still lists it with the reason.
- **AmigaOS-specific advice comes from published sources:** the AmigaOS 3.2, 3.5 and 3.9 FAQs, Aminet readmes, and authors' notes. For example, on 3.2:
  - FBlit and FText: the 3.2 FAQ says FBlit makes the system unstable.
  - VisualPrefs and MCP: they clash with 3.2.
  - PeterK's icon.library 46.4: doesn't run on 3.2.
  - PowerWindows and FreeWheel: 3.2 does this itself.
  - ClassAct, Installer 43.3, LoadModule and picture.datatype V43: 3.2 already includes these.
- **On older systems,** software that needs Workbench 2.0 or 3.0 says so when you're installing 1.3 or 2.x.
- **The suggested set** no longer includes anything advised against for your AmigaOS.

Advice is given only for an AmigaOS this app installs from CD or floppies. A drive imported from elsewhere, such as PiMiga, gets hardware advice only.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
