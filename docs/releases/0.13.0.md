PiStorm Imager now updates itself, and installs from a package.

## Install it from the package

This release publishes `PiStorm-Imager_0.13.0_ubuntu24.04_all.deb`, for Ubuntu 24.04 and Linux Mint 22. The app is pure Python, so the same file serves every architecture. Install it with apt, which brings everything it needs:

    sudo apt install ./PiStorm-Imager_0.13.0_ubuntu24.04_all.deb

It starts from the desktop's application grid, or with `pistorm-imager`.

## It updates itself

Open About and press **Check for Application Updates**. When a newer release is out, the button becomes **Update to X.Y.Z**, and pressing it does the rest:

1. It shows the release's notes and asks before doing anything.
2. It downloads the new package and checks it against the release's published checksums.
3. It asks for your password, checks the package again as root, and installs it.
4. It offers to restart into the new version.

Nothing is installed while a card is being written.

Copies run from a git checkout or installed with pipx still say which command updates them, as before.

## Updating to this release

This is the first release with a package, so earlier copies cannot update to it from inside the app. Install the package once, as above; from then on, About keeps it up to date.
