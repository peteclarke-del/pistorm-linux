A fix for AmigaOS 3.2 cards that stopped at a Shell prompt.

## Fixed

- **An AmigaOS 3.2 card with the PCMCIA software stopped at boot.** It showed *C:CardPatch failed returncode 10* and a Shell prompt, so Workbench never loaded. CardPatch won't run on the 3.2 ROM, and 3.2 runs User-Startup so that any failure there ends the boot.
- **Nothing the imager adds to S:User-Startup can stop the boot now, for any package.** A command that fails is reported, and the boot carries on.
- **CardPatch is now advised against on AmigaOS 3.2.** The 3.2 FAQ recommends CardReset on its own for the A1200's PCMCIA problems.
- **The PCMCIA CD driver no longer brings CardPatch with it.** It still brings CardReset and AmiCDFS.

If you built an AmigaOS 3.2 card with the PCMCIA CD driver or CardPatch, rebuild its System drive. Or on the Amiga, delete the `C:CardPatch` line from `S:User-Startup`. At the Shell prompt it stops at, type `LoadWB` to reach Workbench first.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
