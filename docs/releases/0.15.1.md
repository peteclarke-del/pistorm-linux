A fix for drive sizes changing when a setup is loaded or edited.

## What was wrong

The Drives page showed each drive's size rounded to two decimal places, then read that rounded text back. A 4095 MB system drive came back as exactly 4 GB.

That matters on an A600 or A1200 IDE card. The first drive starts a little way into the card, so a 4 GB system drive ends just past the 4 GB that the machine's own Kickstart can read.

## What changes

Each drive's size is now shown exactly (for example `4095M` or `15G`), so it is the same after loading, editing and saving as when it was set.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
