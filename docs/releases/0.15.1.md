Fixes for AmigaOS 3.2 cards and for the Programs drive.

## AmigaOS 3.2 cards no longer stop at boot on "can't load picture"

Every AmigaOS 3.2 card stopped at startup on *ERROR: can't load picture Sys:Prefs/Presets/Backdrops/default_pal.iff* until **Continue** was pressed. Drawers this tool made were dated 1 January 1978, and AmigaOS decided from that date that there were no picture types to load, so the backdrop could not be shown. Drawers and files are now dated with the time they are made, and a 3.2 card boots straight to its backdrop.

## LoadModule runs on every system drive

The lines that must run before Workbench starts - LoadModule for the IDE driver that reaches past 4 GB, and for icon.library - were only added to a Workbench installed from floppies. A system from the AmigaOS 3.2 or 3.9 CD, PiMiga or an imported drive did not get them. Now it does.

## The Programs drive no longer moves Workbench's Tools drawer

With Emu68's tools kept on another drive, the whole `Tools` drawer was treated as theirs. The boot script then looked for Workbench's Commodities on the Programs drive. Workbench's own drawers now always stay on the system drive.

## Drive sizes stay exact

The Drives page rounded each drive's size for display and then read the rounded figure back, so a 4095 MB system drive became exactly 4 GB. That pushed it just past the 4 GB an A600 or A1200 can read on its own Kickstart. Sizes are now shown exactly.
