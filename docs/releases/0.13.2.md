A fix for the in-app update, which never installed anything in 0.13.0 and 0.13.1.

## Download and Install did nothing

The update is held back while a card is being written. The app decided that from the write window's Cancel button, which counts as visible from the moment the app starts, so every update was refused as though a card were being written. The reason was shown under the button, where it was easy to miss. The app now records when a write starts and ends.

## Updating to this release

Because of this bug, 0.13.0 and 0.13.1 cannot install this update themselves. Install the package once more by hand:

    sudo apt install ./PiStorm-Imager_0.13.2_ubuntu24.04_all.deb

From 0.13.2 on, About installs updates itself.

## If the app still shows an older version

If you installed an earlier version with pipx, its copy and its menu entry come before the package's, so the menu still starts the old one. Remove them:

    pipx uninstall pistorm-imager
    rm ~/.local/share/applications/pistorm-imager.desktop
    rm ~/.local/share/icons/hicolor/scalable/apps/pistorm-imager.svg

Then log out and back in, so the desktop's app grid picks up the package's entry.
