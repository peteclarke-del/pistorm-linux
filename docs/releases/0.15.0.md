Any A600 or A1200 IDE drive can now reach past 4 GB, whatever system is on it.

## What's new

Before Kickstart 3.1.4, the A600's and A1200's built-in IDE driver can only read the first 4 GB of a card. Until now, only an AmigaOS 3.2 install from the CD brought a driver that reaches further. Now any drive gets one: Workbench 3.1 from the floppies, 3.9, or a drive imported from an image.

- The driver is AmigaOS 3.2's own `scsi.device`, taken from your copy in `samples/drivers/A1200` and `samples/drivers/A600`. It comes from the 3.2 CD's Modules disk; `samples/README.md` explains where to find it.
- The build adds LoadModule from Aminet and runs it at startup. LoadModule puts the driver in place and restarts once.
- If a drive reaches past 4 GB and no copy of the driver can be found, the build stops and tells you where the file comes from.

Tested in an emulator: Workbench 3.1 on the A1200's own 3.1 ROM mounted drives out to 16 GB.

## Also

Aminet's current LoadModule archive has one damaged file inside it, which this tool does not use. Archives like that now install whatever passes its checksum, instead of failing as a whole.
