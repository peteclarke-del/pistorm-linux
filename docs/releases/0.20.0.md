The app now suggests which AmigaOS suits your machine, together with the Kickstart and software to go with it.

## What's new

- **A suggestion on the System step,** for example *Suggested: AmigaOS 3.2 on Kickstart 3.2 A1200 (47.96)*. It says what you still need, and you can open it to see why.
- **Use this** chooses the system, the Kickstart to boot it from, and the software suggested for that release.
- **If something is missing,** such as the 3.2 CD, a second button offers the best you can install right now, for example *Use Workbench 3.1 now*.
- **How it decides:** it works the answer out from what each release needs and when it came out, and from your machine, accelerator and screen.
  - With a PiStorm or another accelerator, you get the newest release your machine runs.
  - On a stock 68000, you get the release your machine was made for.
- **3.2 comes with its own 3.2 Kickstart.** Its CD carries those ROMs, so choosing the CD covers the ROM too.
- **On a PiStorm, the Kickstart is the file on the SD card,** so you don't need to fit a ROM chip.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
