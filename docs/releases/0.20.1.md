## Fixed

- **CardReset can now be chosen on its own.** On AmigaOS 3.2, ticking CardReset also ticked CardPatch. The app then warned against CardPatch, and following the advice (CardReset alone, as the 3.2 FAQ recommends) wasn't possible. CardReset's readme only recommends CardPatch, so it no longer brings it along.
- **A package's warning now includes anything it brings with it.** For example, YAM on Workbench 1.3 now says it brings MUI classes that need AmigaOS 3.0. You see that when you tick YAM, rather than only on the extras it adds.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
