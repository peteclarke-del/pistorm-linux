FS-UAE can now run the encrypted AmigaOS 3.9 BoingBag updates during a privileged card build.

## What's new

- **BoingBag 1 and 2 for AmigaOS 3.9 run under FS-UAE when rebuilding a card.** The build passes through the desktop display and X11 authorization needed for OpenGL, and keeps the emulator window hidden.
- **The build log reports what FS-UAE actually did.** If it exits early or cannot finish, its exit status and recent output are included. Successfully applied encrypted files are no longer reported as skipped.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
