A fix for every CF card or IDE drive this tool has built: they stopped with **Software Failure 8000 0008** as soon as an Amiga booted from them.

## What was wrong

The file system handler that lets the Amiga read a PFS3 drive is stored at the start of the drive, in its RDB. It was written so that Kickstart's own loader read past the end of the handler into padding, took that for more of the program, and gave up. The handler never loaded, so the Amiga stopped with a software failure when it tried to boot from the drive. A drive it was not booting from showed as "not mounted".

Emulators load the handler their own way, so they never showed this. PiStorm SD cards were not affected either, because Emu68 loads it its own way too.

## Fixing a card you already have

The card's files are fine; only the handler's blocks at the start of the card are wrong. Either rebuild the drive with this version, or rewrite just those blocks. Only the start of the card changes, and every drive and file stays where it is.

## Updating

If you installed 0.13.2 from its package, open About and press **Check for Application Updates**. Otherwise, install the package from this release.
