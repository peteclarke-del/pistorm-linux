A new task on the first screen: **A PiStorm card from PiMiga**.

## What's new

PiMiga is a Raspberry Pi image that runs an Amiga emulator over four drives: System, Demos, Games and Work. The new task turns those drives into a real PiStorm card.

- **Choose PiMiga's `.img`**, or the folder it's mounted on. The image is opened read-only and is never changed.
- **PiMiga's own requirements are checked before anything is written.** The app reads them from PiMiga's configuration: an RTG screen (so a PiStorm), a 68040 with an FPU (which Emu68 provides), and Kickstart 3.1 for your machine. AGA isn't needed, because with RTG the desktop is drawn on the Pi's HDMI. AGA-only games and demos are left out on other machines.
- **Only what works on a real Amiga is taken.** The emulator's graphics driver is swapped for Emu68's, emulator-only commands are switched off, PowerPC/AROS/MorphOS programs are left out, and the emulator's own bookkeeping files are never copied. The Software step offers to remove the rest, such as PiMiga's "Host Run fun" launchers, which start programs on the Linux host.
- **Networking that works on a PiStorm.** PiMiga's own network setup is for the emulator, so the card gets lwIP and the Pi's WiFi driver (and its Ethernet driver on a Pi 4).
- **Each drive is sized from what's on it,** with room to add more. A card too small for PiMiga is refused before anything is written.

## Also fixed

- A TCP/IP stack's own commands now always replace a same-named command from a different stack. Previously a "newer" version from another stack could be kept, leaving the network commands mismatched.
- The warning that "nothing can launch the games" no longer appears when the system being copied already has WHDLoad.
- Looking through a large drive for things to leave out is much faster, and no longer freezes the window.
