A fix for a CF card or IDE drive built for a PiStorm, as a split build makes them.

## A CF card that stopped with Software Failure 8000 0008

On an A1200, the processor on the board starts first, from the Kickstart soldered to the board, while the Pi is still starting Emu68. In those seconds it could see a CF card on the IDE port and boot it: a 3.2 system on a 3.1 Kickstart, which stopped with a software failure before Emu68 took over.

A drive built for a PiStorm on the IDE side now waits when the Amiga's own Kickstart starts it, and says so on screen. Emu68 then restarts the machine into the Kickstart it loads, and the drive boots normally. After a minute it carries on regardless, so a machine whose PiStorm never starts is not left hanging.

To fix a CF card that is already written, rebuild its system drive with this version: choose **Rebuild one drive**, select the card, and choose the drive the Amiga boots from.

## Updating

If you installed 0.13.0 from its package, open About and press **Check for Application Updates**. Otherwise, install the package from this release.
