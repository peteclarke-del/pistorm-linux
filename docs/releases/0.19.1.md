A fix for AmigaOS 3.2 cards with an RTG screen.

## Fixed

- **An AmigaOS 3.2 card asked for with an RTG screen could be written with no RTG at all.** When the 3.2 warnings left picture.datatype V43 off, Picasso96 was unticked with it, and the switch stayed locked off.
- **3.2 already has a newer picture.datatype, so Picasso96 now uses that one.** The older V43 copy is no longer added, or installed over 3.2's own. The same applies to ClassAct, Installer, DefIcons and LoadModule on the AmigaOS releases that already include them.
- **Anything your display requires can no longer be unticked by something else** while that display is chosen.

If you built an AmigaOS 3.2 card with an RTG screen using 0.18.0 or 0.19.0, check whether it has Picasso96. If it doesn't, rebuild it.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
