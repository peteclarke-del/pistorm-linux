Software for the PCMCIA slot of an A600 or A1200.

## What's new

These are offered only on machines that have the slot:

- **PCMCIA CD-ROM drive (PcmciaCD 1.9)**: drives Sony's PCMCIA CD-ROM drives, such as the PCGA-CD51, which plug straight into the slot and need no power of their own.
  - Double-click **Storage/DOSDrivers/PCD0** to mount the drive. To have it mounted at every boot, move PCD0 to Devs/DOSDrivers.
  - It comes with **AmiCDFS** to read the CDs.
- **CardPatch**: fixes bugs in the A600's and A1200's PCMCIA support. It runs at startup.
- **CardReset**: resets a card that has stopped answering. Run it from a Shell when you need it.

All of them are downloaded from Aminet.

### PiMiga on Kickstart 3.2

- **A card built from PiMiga can now use Kickstart 3.2 as well as 3.1.** On the 3.2 ROM, PiMiga's first boot line (a LoadModule of its own workbench.library) failed, because the ROM's copy is newer. That stopped the boot at a Shell prompt.
- **A LoadModule in any boot script the app copies now can't stop the boot.** It is wrapped in `FailAt 21` / `FailAt 10`, so it's allowed to fail. Tested in FS-UAE: PiMiga boots to its desktop on 3.2.

### Less that only works in an emulator

- **The Software step now finds single emulator-only files**, not only whole drawers. On PiMiga these are:
  - UAE's control programs in C:;
  - the `Tools/Power` script, which shuts down PiMiga's Linux;
  - a DPaint launcher for Linux;
  - UAE's sound modes, which have no driver on a real Amiga;
  - a spare UAE screen driver in Storage.
- **They are ticked for removal by default.**
- **The dock no longer has buttons for programs a card leaves out**, such as PiMiga's Firefox and Chromium.
