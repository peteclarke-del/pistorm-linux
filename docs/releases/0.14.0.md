Software can now be kept on a drive of its own.

## What's new

Each drive on the Drives page has a **Software kept on this drive** list. Tick a kind of software there - Internet, Tools, Pictures, music and video, and so on - and every package of that kind is installed onto that drive instead of the one the Amiga starts from.

That makes room for a layout like System, Programs, Games, Demos and Work, with a System drive small enough for an older Kickstart to start. This matters on an A600 or A1200 IDE card larger than 4 GB.

- Only the programs move. Libraries, commands and settings stay on the system drive, where AmigaOS expects them.
- Everything that refers to a moved program is updated to point at its new drive, so it still starts the same way: startup lines, assigns, icons and scripts.
- The record of what was installed (`S:PiStorm-Installed`) lists the moved programs under their drive's name.
- Each kind of software can be kept on only one drive, and that drive must use FFS or PFS3.

## Updating

Open About and press **Check for Application Updates**, or install the package from this release.
